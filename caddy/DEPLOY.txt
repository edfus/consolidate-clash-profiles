Quantumult X distribution

Only public filter rules belong in caddy/quantumultx/ and GitHub.
Public URL: https://ladyfirst.uk/quantumultx/Anthropic.list
The public Caddy service allows this exact file only; all other paths return 404.

Full configs, packages, server addresses, subscription URLs, passwords and keys must stay under ignored private/ locally. Never commit them. Deploy them separately to /root/C/caddy/config/quantumultx/ on the VPS, served by the existing HTTPS Basic Auth route /.config/quantumultx/. Do not copy them into the public quantumultx directory.
HTTPS encrypts transport and Basic Auth protects access; this does not provide encryption at rest.

Public deployment:
Copy this caddy directory to /root/C/caddy/ without --delete.
cd /root/C/caddy
docker-compose -p profile-quantumultx -f profile-quantumultx.yml config --quiet
docker-compose -p profile-quantumultx -f profile-quantumultx.yml up -d --force-recreate

The main Caddy Docker proxy discovers /quantumultx/*. Existing TLS termination is reused; no new public ports are opened.

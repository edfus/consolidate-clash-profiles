Quantumult X HTTPS distribution

Public files contain no subscriptions or credentials. Keep private profiles.js outside this directory.

Copy this directory to /root/C/caddy/ without --delete (other existing VPS files must stay).
Start/update:
cd /root/C/caddy
docker-compose -p profile-quantumultx -f profile-quantumultx.yml config --quiet
docker-compose -p profile-quantumultx -f profile-quantumultx.yml up -d

The existing Caddy Docker proxy discovers the /quantumultx/* route. Existing Trojan TLS termination and Caddy port 8080 are reused. No additional public port is opened. File-only updates take effect immediately; regenerate ZIP when changing its contents. No directory listing is enabled.
Rollback: docker-compose -p profile-quantumultx -f profile-quantumultx.yml down
